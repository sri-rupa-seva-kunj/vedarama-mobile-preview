# Самопроверка светлого макета — версия 02

Проверка проведена по просьбе пользователя: отступы, качество графики и продуманность сценариев. Рабочее приложение не менялось.

| Найдено | Исправлено |
|---|---|
| Мелкие и неоднородные языковые значки; текстовый значок транслитерации переносится | Подключены исходные SVG каталогов RU/EN/санскрит, конвертора и настроек. PNG значка приложения сохранён, отображается крупнее без растягивания сверх исходного разрешения |
| Неравномерные отступы дерева, полок и заголовков; мелкие подписи | Единые поля 18–24 px, предсказуемая высота кнопок, крупнее подписи и управляющие иконки. Названия полок выровнены слева |
| PNG предыдущего макета недостаточно чёткие при увеличении | Основные состояния отрисованы при DPR 2, 3072 × 2160; интерфейс остаётся HTML, функциональные иконки — SVG |
| Кнопка добавления заметки не создаёт заметку | Редактор с сохранением/отменой, несколько заметок, выбор цитаты, редактирование, удаление и отмена удаления, пустое состояние, реальные счётчики. Данные сохраняются локально |
| Созданная полка не появляется в навигации | Создание, переименование, проверка дубликатов, добавление текущей книги, реальные счётчики, синхронное обновление левого списка и сохранение после перезагрузки |
| AI-композер уходит ниже экрана | История прокручивается отдельно; ввод закреплён внизу. Пустой вопрос заблокирован, черновик сохраняется. Пример диалога явно обозначен как демонстрация; ссылка ведёт к текущему фрагменту |
| Режим чтения теряет прежнее состояние панели | После выхода возвращаются заметки или AI. Кнопка дерева возвращает автоматически скрытое дерево и при необходимости закрывает инспектор |
| Размер интерфейса меняется не везде | Размеры текста дерева и основных подписей зависят от выбранного масштаба; настройки получили предпросмотр и выровненные контролы |
| Неподключённые крестики вкладок выглядят действующими | Убраны ложные элементы закрытия. Полная работа вкладок остаётся задачей рабочего приложения |
| Поддержка не имеет полезного локального действия | Добавлено сохранение черновика без внешней отправки |

Проверки: 21 успешный браузерный сценарий, результаты в audit-v2-results.json; воспроизводимый скрипт tmp/audit-light-v2.cjs. Проверены 1536×1080, 1088×760 и 390×844, сохранение после перезагрузки, масштабирование 22 px текста/18 px интерфейса, пустые состояния и отмена. Все основные состояния просмотрены визуально, включая короткое окно AI и мобильную компоновку. Предыдущие снимки сохранены в before-audit/.

Границы: это интерактивный прототип. Реальные AI, серверный поиск, онлайн-загрузка книг, переходы к другим стихам и отправка сообщений не подключены. Сложная привязка аннотаций после обновления издания и полная система вкладок требуют реализации в приложении.
