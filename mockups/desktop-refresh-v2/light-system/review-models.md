# Мои модели — дополнение 4.3

Референс: текущий DesktopModelManagement.tsx, modelProviders.ts и modelConnectionForm.ts из локальной десктопной сборки Ведарамы. Проект-источник: .codex-work/vedarama-rag-ai-desktop/chat/src; наличие формы проверено также в windows-desktop-work/qml/Ai/DesktopChatBundle.js. Рабочее приложение не изменено.

В макете добавлены:

- Выбор модели и кнопка «Мои модели» над диалогом — в режиме страницы и рядом с книгой.
- Отдельная страница со списком подключений, добавлением, редактированием, выбором и удалением с подтверждением.
- Провайдеры из видимой текущей формы: OpenAI, DeepSeek, Claude, свой API URL. Значения по умолчанию перенесены из исходника, а не представлены как актуальный каталог доступности моделей.
- Название подключения, идентификатор модели, API URL, поле ключа с показом/скрытием.
- Дополнительные параметры: протокол, режим рассуждения, размер контекста, лимит ответа.
- Проверка заполнения формы перед сохранением. Изменение данных сбрасывает проверку.
- Возврат в предыдущий режим чата без потери черновика. Доступ из мобильного меню «Ещё».
- Сохранение метаданных и выбора модели в браузере. API-ключ исключён из сохранения; сетевые запросы к провайдерам отсутствуют. Демо-проверка явно не заявляет реальное соединение.

Проверены 20 сценариев в audit-models-results.json: выбор, добавление, проверка и её сброс, отсутствие ключа в хранилище, возврат в оба режима, показ ключа, отмена и подтверждение удаления, недопустимый URL, прямой переход, мобильная компоновка 320/390/430 px. Скриншоты обеих тем просмотрены. После просмотра исправлено начало прокрутки формы; неверные числовые поля автоматически раскрывают блок дополнительных параметров.

Макет: ?v=4.3&section=models. Для имитации проверки используйте demo-key. Для реального подключения при реализации потребуется существующий серверный механизм десктопной Ведарамы; он в дизайн-макет не переносился.
